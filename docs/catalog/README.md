# Model claims

Model-specific claims the provider adapters deliberately do not apply, since
capabilities are provider-level (ADR 0015). Each row records its trigger model
ids, the adapter's former behaviour, the evidence (provider-doc URLs and
quotes), and whether the upstream refusal is mapped. They are the input for
the planned opt-in model catalog. Row IDs are stable and cited from code and
ADRs; do not renumber them.
