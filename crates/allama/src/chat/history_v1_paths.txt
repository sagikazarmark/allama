# Paths follow the same form as accounted_fields.txt: arrays add `[]`, and an
# object tagged with `role` or `type` adds its tag as a segment. A path ending
# in `{}` holds free-form JSON (provider data, application data, `Other` wire

# of the format.

# every message, content and source kind and every field set, and fails when
# a path appears or disappears. That is a format change: after 0.1 it bumps
# `HISTORY_FORMAT_VERSION`, in a minor release only.
